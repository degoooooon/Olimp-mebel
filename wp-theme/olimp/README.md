# Тема «Олимп»

**Файлы в этой папке не редактируются руками.**

- `front-page.php` и `assets/` собираются командой `npm run build:theme`
  из `src/` в корне проекта. Правки здесь исчезнут при следующей сборке.
- Править надо `src/index.html`, `src/styles/`, `src/js/` — и пересобирать.

## Как обновить сайт

1. `npm run build:theme`
2. Залить папку `wp-theme/olimp` в `/wp-content/themes/` на хостинге
3. Активировать тему в админке (только в первый раз)

## Как добавить товар

Раздел **Товары** в админке, кнопка «Добавить товар». Один товар —
одна запись. Плагины не нужны, всё своё.

**Заголовок** — название товара, оно же попадёт на карточку.

**Изображение записи** — фотография, блок справа. Загружается одна,
три размера под разные экраны тема нарежет сама.

**Категории** — блок справа. Новые заводятся там же или в разделе
«Категории». Товар без категории попадёт в каталог, но не попадёт
ни под один фильтр.

**«Цена и наличие»** — блок справа, четыре поля:

| поле | что делает |
|---|---|
| Цена, ₽ | пустое — на карточке будет «Цена по запросу» |
| Старая цена, ₽ | если больше текущей, на карточке появится размер скидки |
| В наличии | снять галочку — кнопка «В корзину» станет неактивной |
| Новинка | плашка на карточке, ставится вручную |

**Новинку отмечайте выборочно.** Раньше она считалась сама по дате
публикации — и когда весь каталог залили за один день, плашка встала
на все 41 карточку. Плашка, которая есть у всех, не значит ничего.

**Порядок в выдаче** — поле «Порядок» в блоке «Атрибуты» справа.
Число: меньше — выше в каталоге. У товаров с одинаковым числом первыми
идут те, что добавлены позже.
