# Справочник по модулям

Собран из комментариев JSDoc прямо в коде командой `npm run docs`.
Это не отдельный документ, который надо поддерживать руками: он
пересобирается из исходников, и разойтись с ними не может.

## С чего начать

Справочник отвечает на вопрос «что делает эта функция и что ей передать».
На вопрос «как всё устроено» отвечают другие документы:

- **[README проекта](https://github.com/degoooooon/Olimp-mebel#readme)** —
  карта файлов и схема, как данные из админки WordPress доходят до карточки
- **[docs/catalog-data.md](https://github.com/degoooooon/Olimp-mebel/blob/main/docs/catalog-data.md)** —
  формат каталога: договор между темой и браузером
- **[docs/journal.md](https://github.com/degoooooon/Olimp-mebel/blob/main/docs/journal.md)** —
  дневник: что ломалось и почему код выглядит именно так

## Как читать

Модуль `data.js` — точка входа для данных. Там же описаны типы `Product`,
`Category`, `Spec` и `Shot`: это форма товара, на которую ссылаются
остальные модули.

Дальше по убыванию важности: `catalog.js` — вся логика витрины,
`cart.js` — корзина, `url-state.js` — состояние каталога в адресе страницы.

Модули `dom.js` и `utils.js` — вспомогательные, их читают по ссылке
из других мест, а не подряд.
